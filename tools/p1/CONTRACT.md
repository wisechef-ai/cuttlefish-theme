# P1 design-sprint contract (cf2909)

This is shared by the 3 direction lanes, the host-harness lane (H) and the gate lane (G). The P1-LEAD
owns it; change it only via the lead. Plan: vault `projects/cuttlefish-theme/PLAN-v22-fresh-ground.md`,
brief: `sprint-2909/P1-brief.md`.

## 1. Fixture

`tools/p1/stub-sessions.json` (generated by `make_stub_sessions.py`; `--check` guards freshness).
It holds 20 sessions (name, lineage_id, `hue_deg` = OKLCh hue in the identity arc [110°, 340°), state,
`alarm_text`) plus a `degraded` entry. **Every direction renders this file, and nothing else.**

## 2. Direction module: `design/directions/<id>/direction.mjs`

This is a pure ESM module with **no imports**, no timers and no I/O. It runs unchanged inside the TUI
widget (Node) and the desktop plugin (browser). Every export is a pure function of its arguments.

```js
export const meta = {
  id: 'a-mottle',              // kebab, equals the directory name
  name: 'Human name',
  biology: 'one line: which Sepia/Metasepia body patterns, per state',
  maxColorsWorking: 48,        // D1 / spike 13: working palette budget (≤ 48)
  fps: 4,                      // working only; ≤ 4
};

// Paint one frame into a logical-pixel buffer.
//   scale: 'XL' (desktop field pane) | 'M' (TUI mantle / desktop chip) | 'S' (TUI pill / desktop swatch)
//   w, h:  logical pixels. Harness choices: TUI mantle M = (cols-2) × (rows*2) on the half rung and
//          (cols-2) × rows on the bg rung. Your pattern MUST read at the bg rung (1×2 px per cell, tall cells 10×22 px).
//   state: 'idle'|'working'|'review'|'needs-you'|'fault'|'unknown'
//   session: one entry from stub-sessions.json, or the `degraded` entry (hue_deg === null → no identity hue)
//   t:     seconds (float). Non-working states MUST return identical pixels for every t (only working animates, D1).
//   opts:  { reducedMotion: bool, depth: 'truecolor'|'256' }  (reducedMotion → working is static too)
// Returns { pixels: Uint8ClampedArray(w*h*4) RGBA, text: [{x, y, str, fg:'#rrggbb', bg?:'#rrggbb'}] }
//   `text` = literal overlays in CELL coordinates for M/S (x=col, y=row), CSS px for XL.
//   Alarms MUST carry session.alarm_text literally (`INPUT 4m`, `ERROR 2m`); unknown carries `?`;
//   M and S carry the session name (durable label). Text pairs are gated at ≥ 4.5:1 (G2).
export function paint({ scale, w, h, state, session, t, opts }) { ... }

// Optional: the colours you use for text/background pairs, for the G2 contrast table.
export function authoredPairs() { return [{ fg: '#..', bg: '#..', where: 'M alarm text' }, ...]; }
```

Rules (plan L7, D1, P1-brief §4): hue = identity, pattern = state. Never use amber/red as an identity hue,
and use them only on alarm states. Structure beats shading (it must survive the 256 rung and deutan/protan/tritan sims).
Only `working` changes with `t`: a slow passing cloud, ≤ 48 colours, ≤ 4 fps. Degraded/unknown is a designed look.

## 3. Hosts (lane H provides these; directions do not write capture code)

- `tools/p1/hosts/tui-stub-widget.mjs`: a real TUI widget (`$HERMES_HOME/tui-widgets/`) that imports a direction
  by absolute path from `CF_P1_DIRECTION`, reads the fixture and a `CF_P1_SCENE` json (`{view, state, session_idx,
  frame_t}`), and paints mantle (M), pill row (S), or the 16/20-session identity grid through the half or bg rung
  (the 256 quantisation is done by the adapter, not the direction).
- `tools/p1/hosts/desktop-stub/plugin.js`: a real desktop plugin named **"Cuttlefish"** with a field pane (XL),
  a status-bar chip (M) and a session-row swatch (S). The scene is switchable in-page so one Electron boot captures everything.
- `tools/p1/capture_matrix.py --direction design/directions/<id> --out <dir>` renders the full matrix through
  the real hosts and writes `manifest.json` (below). One command per direction.

## 4. Render output and manifest (what G2/G5 consume)

Output root: vault `projects/cuttlefish-theme/p1/renders/<direction-id>/` (PNGs out of the public repo),
with `manifest.json`:

```json
{ "schema": "cf2909.p1.manifest/1", "direction": "a-mottle", "hermes_sha": "…", "plugin_sha": "…",
  "entries": [ { "file": "tui/M-half-tc-120-needs-you.png", "host": "tui-terminator|tui-pane-webgl|tui-pane-dom|desktop",
                 "scale": "M", "state": "needs-you", "rung": "half|bg|dom", "depth": "truecolor|256",
                 "cols": 120, "session_idx": 1, "sessions": [1], "frame_t": 0.0,
                 "crop": [x, y, w, h], "capture_log": "logs/….log" } ] }
```

The required matrix per direction: TUI M (6 states + degraded) × {half-truecolor, half-256, bg-webgl, bg-dom} at
120 cols, plus half-truecolor at 80 cols; TUI S pill for 6 states; TUI identity grid at 16 and 20 sessions;
desktop XL, M and S for 6 states + degraded; a desktop 20-row sidebar (identity); working at 4 frames
(t = 0, .25, .5, .75), and every other state at 2 frames (it must be byte-identical: the static proof).
Each `capture_log` records the command line, the host process list (`ps` of the hermes / electron pids),
both SHAs and the HERMES_HOME (a temp dir). **A render with no capture log does not count** (premortem #1).
Browser mockups do not count.

## 5. Gates (lane G builds them; the lead runs them)

`gates/g2.py <manifest>` and `gates/g5.py <manifest>`. The thresholds are in plan §5 and the P1-LEAD card:
contrast ≥ 4.5:1 on authored pairs; identity separation on rendered pixels at 16 and 20; colour-blind sims still name
the state from pattern; G5 median ≥ 7, none < 6, legend naming ≥ 80 %, INPUT↔ERROR confusions = 0, identity 16 → ≥ 14/16.
